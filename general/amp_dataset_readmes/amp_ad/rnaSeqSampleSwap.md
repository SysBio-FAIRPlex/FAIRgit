###The rnaSeqSampleSwap study
This study is an [AMP-AD](https://adknowledgeportal.synapse.org/Explore/Programs/DetailsPage?Program=AMP-AD) cross-consortia project . Teams from the Mayo Clinic, Rush University, Broad, and Mount Sinai School of Medicine generated RNAseq data on samples originating from the [ROSMAP](https://adknowledgeportal.synapse.org/Explore/Studies/DetailsPage?Study=syn3219045), [MayoRNAseq](https://adknowledgeportal.synapse.org/Explore/Studies/DetailsPage?Study=syn5550404), and [MSBB](https://adknowledgeportal.synapse.org/Explore/Studies/DetailsPage?Study=syn3159438) to help identify site-specific effects present in these RNAseq datasets, a small number of samples were sequenced at multiple sites. Each site receiving samples for the swap used their own library prep and sequencing protocols to maintain consistency with the data generated at that site for the AMP-AD project.

** Samples Swapped**
10 samples from the ROSMAP study were sequenced at the Broad, Mayo Clinic, and MSSM facilities.
10 samples from the MSSM Brain Bank study were sequenced at Mayo Clinic and MSSM.
10 samples from Mayo RNAseq study were sequenced at MSSM and Mayo Clinic.

###ROSMAP RNASeq Samples Sequenced at MSSM
**Sequencing**: RNA-Seq sample preparation was performed using the TruSeq RNA Sample Preparation Kit v2 (Illumina, San Diego, CA). Briefly, rRNA was depleted from total RNA using the Ribo-Zero rRNA Removal Kit (Human/Mouse/Rat) (Illumina, San Diego, CA) to enrich for coding RNA and long non-coding RNA. The cDNA was synthesized using random hexamers, end-repaired and ligated with appropriate adaptors for sequencing. The library then underwent size selection and purification using AMPure XP beads (Beckman Coulter, Brea, CA). The appropriate Illumina recommended 6-bp bar-code bases are introduced at one end of the adaptors during PCR amplification step. The size and concentration of the RNAseq libraries was measured by Bioanalyzer (Agilent, Santa Clara, CA) and Qubit fluorometry (Life Technologies, Grand Island, NY) before loading onto the sequencer. The Ribo-Zero libraries were sequenced on the Illumina HiSeq 2500 System with 100 nucleotide single end reads, according to the standard manufacturer’s protocol (Illumina, San Diego, CA).

**Data processing**: The raw sequence reads were aligned to human genome hg19 with the star aligner (v2.3.0e). Then the gene level expression (read counts) were quantified by featureCounts (v1.4.4) from the Subread package.

###ROSMAP RNAseq Samples Sequenced at Mayo Clinic
**Summary**: Gene expression measures were generated, using next-generation RNA sequencing (RNAseq), from Dorsolateral Prefrontal Cortex RNA samples collected for 10 subjects from the Rush-Broad ROSMAP study.

**Details**: RNA samples were randomized prior to transfer to the Mayo Clinic Medical Genome Facility Gene Expression and Sequencing Cores for library preparation and sequencing. The TruSeq RNA Sample Prep Kit (Illumina, San Diego, CA) was used for library preparation. The library concentration and size distribution was determined on an Agilent Bioanalyzer DNA 1000 chip. Illumina HiSeq 2000 sequencers were used for 101 base pair (bp) paired end sequencing with triplicate multiplexing of barcoded samples (3 samples per flowcell lane). Note that these data are released in both raw and normalized format. The covariate file includes sample ID, source, tissue, RIN (RNA integrity number, measure of RNA quality), subject diagnosis, gender (F, female; M, male), and age at death (in years) and sequencing flow cell.

**Bioinformatics methods**: SNAPR is an RNA sequence aligner based on SNAP ($$\(arXiv\)$$ technical report 1111.5572v1, Nov. 2011). Alignment with SNAPR starts with the creation of a hash table built from both a reference genome GRCm38 and transcriptome GRCm38.77. This requires a large memory footprint (>40MB) to load the hash table into memory. Starting with fastq files, SNAPR filters reads by Phred score (80% of the read must be have a PHRED score <= 20) and outputs a sorted BAM file and read counts for each sample. Read counts are given by gene ID and transcript ID (two separate files). We have previously tested the read counts generated by SNAPR to the read counts generated by HT-Seq and found them to be very comparable.

**Explanation of available files and post-processing**: As referenced in the provenance, the individual read count files are merged with merge_count_files.R and the appropriate data-set-specific readcount merge script. These scripts generate the corresponding \_counts.txt.gz files. These merged counts are normalized with the \_normalize\_readcounts.R script that uses the edgeR implementation of TMM to calculate CPM. Normalized counts are saved as files with the \_counts\_normalized.txt.gz suffix.
