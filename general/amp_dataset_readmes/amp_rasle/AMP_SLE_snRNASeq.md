# AMP SLE snRNASeq

This dataset contains single-nucleus RNAseq data from kidney tissue collected from 50 subjects. Includes raw fastq files, output from 10x Genomics Cellranger software, processed data files in .Rds format for loading into R, and metadata files, all of which are under controlled access restrictions.
